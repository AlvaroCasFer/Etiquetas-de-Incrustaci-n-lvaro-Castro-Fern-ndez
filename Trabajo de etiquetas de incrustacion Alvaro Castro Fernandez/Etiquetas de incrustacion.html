Etiquetas de Incrustacion

¿ Que son las etiquetas de incrustacion ?

Las etiquetas de incrustacion son una serie de etiquetas las cuales tienen la funcion de meter recursos externos del html como imagenes, audio, mapas etc...


A continuacion se mostrara una tabla con varias etiquetas de incrustacion:

Demostracion

Tipo de etiqueta

Explicacion

Imagen

 Inserta una imagen en el HTML, se le puede indicar tanto la ruta de la imagen o el nombre de la imagen si esta en la misma carpeta que el html

Video

 Puedes insertar videos ya sean descargados e introducido en la carpeta donde esta el html como un enlace a un video de youtube

Audio

 Añade una pestaña en la cual puedes escuchar audio dentro de la pagina web

Iframe

 Permite insertar un documento html dentro de la pagina web principal

Plugguins

 Incrusta contenido externo como aplicaciones interactivas unsando plugguins

Contenido externo

 Se usa para incluir contenido de etiquetas anteriores como img video etc, aparte de poder meter tambien pdfs, mapas etc

Grafico

 Permite renderizar graficos, animaciones, videojuegos en tiempo real

Grafico

 Se genera una forma vectorial dependiendo del codigo
